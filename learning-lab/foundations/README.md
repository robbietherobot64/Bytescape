# Foundations Track: Learn Coding Before Codebase Deep Dives

This track comes before Week 1 architecture lessons.

Purpose: build core programming confidence first, then apply those concepts to Bytescape.

## Learning Outcomes

After this Foundations track, you should be able to:

1. Read basic TypeScript and Rust syntax without panic.
2. Explain variables, types, conditionals, loops, and functions.
3. Understand async/await and Promise-based flows.
4. Use basic debugging and test feedback loops.
5. Recognize the same concepts inside Bytescape files.
