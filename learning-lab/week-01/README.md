# Week 1: Runtime Flow, Contracts, and First Stability Fix

## Week 1 Outcome

By the end of this week, you should be able to:

1. Explain how the app boots and where global wiring happens.
2. Trace profile media loading from UI to Rust and back.
3. Compare one Rust type and one TypeScript type and spot mismatch risk.
4. Run a guided debugging loop for media previews without trial-and-error guessing.

## Session Plan (6-10 hours total)

1. lesson-01-backend-frontend-flow.md (90 min)
2. lesson-02-types-and-commands.md (90 min)
3. lesson-03-media-debug-playbook.md (90 min)
4. project-01-profile-media-previews.md (3-5 hours)
5. Reflection in progress-tracker.md (30-60 min)

## How To Use This Week

For each lesson:

1. Read the lecture section first.
2. Follow the guided walkthrough in order.
3. Compare your findings against the answer key in the same file.
4. Log only final takeaways and questions in progress-tracker.md.

## Week 1 Definition Of Done

- You can name the exact commands used by profile media loading.
- You can point to where those commands are registered and implemented.
- You can explain why image previews might fail without reintroducing memory-heavy fallback behavior.
- You complete the guided project with verification commands.
